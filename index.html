DigitalID Nexus - National Digital Identity Management System

Full-Stack Group Project Associated with SLIIT City UNI Oct 2025 - Nov 2025

DigitalID Nexus is a full-stack National Digital Identity Management System built as an academic group project to support secure citizen registration, identity search, and digital driving license workflows.

Project Screenshots

Key Features

  • - Citizen digital identity registration and management (NDI system)
  • - Driving license application and status tracking
  • - Advanced identity search using NDI ID and NIC
  • - RESTful API architecture for scalable backend communication
  • - Responsive mobile-friendly UI with reusable web components
  • - Centralized database for persistent structured data storage

Technologies Used

  • - Frontend: HTML, Tailwind CSS, JavaScript (Custom Web Components)
  • - Backend: Node.js, Express.js
  • - Database: MongoDB (Mongoose ODM)
  • - Tools: MongoDB Compass, Postman, Git, npm
  • - Architecture: MVC-style Routes, Models, Controllers

My Contributions & Outcome

  • - Designed and implemented the Express.js REST API
  • - Integrated MongoDB with Mongoose and created core data models
  • - Implemented CRUD operations and search endpoints
  • - Built reusable Navbar and Footer web components
  • - Ensured responsive layout and optimized client-server communication
  • - Delivered a fully functional identity system and strengthened full-stack API experience
