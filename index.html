LeafGuard AI 🌿

Computer vision · crop disease detection

An AI-powered tool that diagnoses plant leaf diseases from a single photo — giving farmers a fast, free, first-line diagnosis without waiting for expert access. Classifies leaves into 38 categories across 14 crop species using transfer learning on MobileNetV2, trained on ~87,000 labeled images.

PythonTensorFlow / KerasMobileNetV2Streamlitscikit-learnGoogle Colab (GPU)
View on GitHub →
Details
Built
  • Fine-tuned MobileNetV2 CNN, last 20 layers unfrozen for fine-tuning
  • Classification head: Global Average Pooling → Dropout → Dense (38, softmax)
  • Data augmentation (flip, rotation, zoom, brightness) plus early stopping
  • Streamlit demo app returning a label, confidence score, and top-3 breakdown
Learned
  • Transfer learning and fine-tuning workflows on a pretrained CNN
  • Structuring an end-to-end ML project for public presentation
  • Evaluating a multi-class model and communicating its limitations honestly
